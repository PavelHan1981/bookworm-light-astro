## LTE CAT 1模块的特点及其主要应用领域


LTE CAT1规范在2008年的3GPP Release 8中首次发布，在数据规格上可以提供10Mbps下行和5Mbps上行的通信能力，其目标主要是用于替换已经日薄西山的2G和3G模块在IoT领域中的应用，为这类计算资源受限、不需要太多通信带宽的应用提供可以连接4G网络基站的低成本通信解决方案。


LTE CAT 1模块所具备的典型应用特点使其非常适合用于各种IoT应用：

- 可以提供中等带宽的通信能力。
- 功耗较低，尤其是相比于那些可以提供更高通信吞吐率的LTE规范，例如CAT4及其以上。
- 模块价格较低，目前LTE CAT 1模块价格普遍只有CAT 4模块的一半。
- 可以连接到所有的4G基站上，网络通信的覆盖范围更宽广。相比之下LTE-M和NB-LTE因为技术差异太大，无法连接到普通的4G基站上。
- 语音通话功能支持（LTE CAT 1可以支持VoLTE）等。

## LTE vs LTE-CAT 1 vs LTE-M


与LTE CAT1技术相比，LTE的更高规格模块（例如CAT 4及其以上）虽然可以提供远高于CAT 1的通信能力，但是功耗和复杂度更高，随之导致的硬件成本也更高；而各种LPWAN类型的通信技术（例如LTE-M）在功耗和通信的穿透能力上相比有更好的表现，但是这些技术普遍通信速率比较低以及通信覆盖范围也很小。因此，介于以上两种技术中间的LTE CAT 1技术则在各个方面得到了更好的平衡，因此更适合与对于通信带宽、成本、功耗、网络覆盖范围乃至语音通话能力等有一定要求的IoT应用。


以下是LTE、LTE CAT 1以及LTE-M三种技术在各个维护上的指标对比：


![da4ad790-acad-450b-8fba-1aabc4300c08.png](/images/blog/LTE-CAT-1技术的相关信息汇总-2.png)

- 在基本的通信规格参数上，LTE CAT1与其简化版本LTE CAT 1bis一样，都是使用20MHz频宽，下行速率10Mbps，上行速率5Mbps，通信延迟小于100ms。
- 与LTE CAT1技术相比，NB-IoT以及LTE-M这类LPWAN技术的最大问题是，无法接入到现有的4G基站上，必须独立架设基站或者对当前的4G基站在软硬件方面做一些特殊的升级，对基站存在比较大的兼容性问题，这样的话就严重影响了其应用的范围和产品领域。
- 我们的智能手机上所使用的LTE及其5G芯片动辄可以提供数百兆的通信吞吐率，但是同样的也增加了LTE模块的硬件成本、系统复杂性和功耗。而实际上，对于绝大多数的IoT类型的应用而言，根本用不到太高的通信速率，但是对硬件成本和功耗则比较敏感，因此在这类应用中使用LTE CAT 1模块就更加合适。
- 在绝大多数IoT应用中，LTE模块的流量都是上行流量（例如向网络上传IoT设备采集的音视频数据和传感器数据等），因此为了进一步降低待机功耗，LTE CAT 1技术专门开发了一个低功耗模式PSM（Power Saving Mode），可以让模块在不进行数据传输的时候进入休眠模式，这样就可以极大地降低通信中的功耗。

## LTE CAT 1bis


LTE CAT 1bis是LTE CAT1的简化版本，在2017年的3GPP Release 13规范中首次发布。**实际上今天我们大部分情况下所说的LTE CAT 1实际上指的都是LTE Cat 1bis。**


与LTE CAT 1一样，LTE CAT 1bis同样可以无缝的接入到所有已部署的4G基站上，但LTE CAT 1bis在标准的LTE CAT1的基础上，在技术层面上进一步简化以降低成本。**LTE CAT 1bis在技术上的简化主要是去掉了CAT 1模块中Rx天线的分集天线，在Rx上只保留一个天线。**


![image.png](/images/blog/LTE-CAT-1技术的相关信息汇总-3.png)


这样做的好处是硬件设计更简单，少一根天线模块的尺寸更小，成本更低，在信号好的情况下可以提供与LTE CAT 1模块相同的通信吞吐率，但是因为去掉了Rx的分集天线，也就导致1bis模块的接收灵敏度相比同样条件下的CAT 1模块低3dB。


![image.png](/images/blog/LTE-CAT-1技术的相关信息汇总-4.png)


使用CAT 1bis模块的另外一层顾虑是，CAT 1模块在全世界的绝大多数网络运营商都没有太大的兼容性问题，但是1bis模块的使用在运营商接入方面的兼容性和支持的全面性上相比CAT1模块要差一些。例如部分北美运营商不支持在1bis模块上使用语音通话VoLTE的功能。
