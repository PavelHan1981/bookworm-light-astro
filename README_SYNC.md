# Notion 文章同步脚本 (sync.mjs) 使用指南

该脚本用于将 Notion 数据库中的文章及其图片自动下载并转换为本地 Astro 项目所需的 Markdown 格式。

## 🚀 基础用法

在项目根目录下运行：

```bash
node sync.mjs
```

默认情况下，脚本会尝试同步 Notion 数据库中的所有文章，并按日期倒序（从新到旧）处理。

## 🛠️ 进阶选项

你可以通过命令行参数来精确控制同步的内容：

### 1. 限制同步数量 (`--limit` 或 `-n`)
如果你只想同步最新的几篇文章，可以使用此参数。

```bash
# 仅同步最新的 5 篇文章
node sync.mjs --limit 5

# 或者缩写形式
node sync.mjs -n 3
```

### 2. 按标题过滤 (`--title` 或 `-t`)
如果你只想同步特定的文章，可以使用此参数进行关键词匹配（支持部分匹配）。

```bash
# 同步标题中包含 "底层原理" 的文章
node sync.mjs --title "底层原理"

# 或者缩写形式
node sync.mjs -t "架构"
```

### 3. 组合使用
你可以同时使用多个参数来精确定位。

```bash
# 同步最新的一篇标题包含 "Node.js" 的文章
node sync.mjs -t "Node.js" -n 1
```

## 📁 输出说明

- **文章内容**：保存在 `src/content/posts/` 目录下，文件名为文章标题。
- **图片资源**：文章中的图片会被下载到 `public/images/blog/`，并自动更新 Markdown 中的引用路径。
- **Frontmatter**：脚本会自动提取 Notion 中的标题、日期、描述、分类和标签，生成符合本项目规范的元数据。

## ⚠️ 注意事项

- 请确保你的 Notion 数据库包含以下属性字段：`title` (标题), `date` (日期), `summary` (摘要), `category` (分类), `tags` (标签)。
- 如果下载图片失败，脚本会跳过该图片并继续处理，不会中断整个同步进程。
